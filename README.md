# Volkstuinvereniging Lisserbroek

Website van Volkstuinvereniging Lisserbroek.

De website wordt voorbereid voor publicatie via GitHub Pages. Contactgegevens en domeinnaam volgen later.

## GitHub Pages

Na het toevoegen van de websitebestanden: ga naar **Settings → Pages**, kies **Deploy from a branch**, selecteer `main` en `/ (root)` en sla op.

De homepage staat dan op `https://volkstuin.github.io/website/`.
